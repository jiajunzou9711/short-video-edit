# 给智能体的安装入口

用户把仓库链接交给你并要求安装时，执行以下流程。主流程是通用 Markdown 指令加本地 Python/FFmpeg，不依赖某个模型厂商或特定聊天产品。需要本地文件读写、命令执行和联网能力；平台上传另外需要可操作的已登录浏览器。缺少某项能力就如实说明，不声称已完成对应环节。

## 1. 获取并定位

首次从仓库 README 和安装入口开始；下载或 clone 本仓库到持久目录。安装后直接读取 skill 根目录的 `SKILL.md`；本文件与 ASR_SETUP.md 均包含在安装后的 `references/` 中。已有 checkout 先检查本地修改，不做强制重置。不从本仓库读取、推断或复制作者的任何凭据。

按当前宿主 agent 的实际设置找到技能目录；以已知宿主配置为准。支持 `SKILL.md` 的宿主使用原生技能目录；不支持的宿主可保留仓库，每次执行前读取该文件并调用脚本。不要为了安装而改写宿主的全部全局指令。已有同名 skill 不覆盖，先比较差异。

## 2. 安装和依赖

需要 Python 3.10+。将下列路径替换为刚定位的实际路径：

```sh
python3 daily-article-video/scripts/setup.py install --skills-dir <宿主的技能父目录>
```

安装器复制 skill，并在安装目录的 `.venv` 中安装 Pillow，不向系统 Python 安装包。它返回实际 `installed_skill` 和 `python` 路径。此后使用返回的 Python 调用 `setup.py`、`pipeline.py` 和 `finalize.py`；Windows 的虚拟环境解释器路径不同，使用返回值即可。`--skip-deps` 只复制文件，不能据此宣称依赖就绪。

运行安装后的本地检查：

```sh
<返回的Python路径> <安装目录>/scripts/setup.py doctor
```

检查失败时根据 JSON 中的缺失项修复：

- `ffmpeg` / `ffprobe`：用当前系统可靠的软件包管理器安装 FFmpeg；不隐式执行 sudo 或提权操作，遵守宿主权限。
- `pillow`：确认正在使用安装器返回的虚拟环境解释器。
- 字体：macOS 有默认中文字体；其他系统选择已安装、含中文字形的真实字体文件，配置 `DAILY_VIDEO_FONT` 和 `DAILY_VIDEO_CARD_FONT`，再核对实际渲染。不得把文件存在等同于排版通过。
- ASR：执行下一节。缺少认证时只暂停依赖该认证的步骤，其他安装工作继续。

无需浏览器即可完成安装、诊断和本地媒体处理；没有浏览器能力时提供成片和手动上传材料，不虚构已上传状态。

## 3. 语音转文字配置

先读 [ASR 配置指南](ASR_SETUP.md)。`doctor` 只判断凭据是否配置，不显示值、不发请求。优先复用使用者已有的本地配置或安全注入的环境变量，不打印、上传或复制已有密钥。

缺少凭据时，给使用者官方控制台/文档链接，让其自行登录、开通正确服务并取得凭据。不要索要其主账号密码，不代替其支付或接受协议，不绕过认证。

推荐使用者在本机交互终端运行：

```sh
<返回的Python路径> <安装目录>/scripts/setup.py configure-asr
```

密钥输入不回显，保存到仓库外 `~/.config/volc.env`；`VOLC_CONFIG_FILE` 可指定其他位置。已有文件不会被覆盖。POSIX 新文件使用 `0600` 权限；Windows 需检查仅当前用户可访问的 ACL。不要让使用者把密钥发到聊天，也不要把密钥放进命令行参数、README、提交或安装日志。

## 4. 验证并交付

重新运行 `doctor`。本地配置存在不代表账号、资源权限或额度有效，不能把它称为“转写已验证”。

要做在线验证，先获得使用者对一个不超过 30 秒的样例音频上传至豆包语音、可能计费的授权，再运行：

```sh
<返回的Python路径> <安装目录>/scripts/setup.py verify-asr --audio <已获准的短音频路径> --allow-upload
```

该命令调用真实转写接口，检查可用的字级时间戳，仅输出状态；临时音频和响应会删除，不回显转写。不要为了安装而擅自拿使用者的整段视频测试。无样例或无上传授权时完成本地配置并注明“在线转写未验证”。

交付实际安装目录、后续使用的 Python 路径、依赖缺失项、本地配置和在线验证状态。说明宿主是否需要重新加载技能。完成标准：文件已安装、依赖检查通过、转写配置状态明确；在线验证、音频审听和平台上传能力分别报告，不一概承诺所有 agent 或系统都已兼容。
